Теоретическая часть:

1. Объясните, как подключить и использовать flexbox в CSS.
   Приведите пример базового контейнера с применением display: flex;

Ответ:
    Flexbox - это инструмент CSS для гибкого расположения элементов внутри контейнера.

    Для подключения flexbox необходимо задать контейнеру свойство:
    display: flex;

    После этого все дочерние элементы контейнера становятся flex-элементами
    и начинают располагаться по flex-правилам.

    Пример базового flex-контейнера:

    .container {
        display: flex;
    }

    По умолчанию элементы располагаются в строку слева направо.

2. Опишите основные свойства, используемые для управления элементами flexbox:
   1) Для контейнера: flex-direction, justify-content, align-items, align-content, flex-wrap.
   2) Для элементов: flex, flex-grow, flex-shrink, flex-basis, align-self, order.

Ответ:
    Свойства flexbox делятся на свойства контейнера и свойства flex-элементов.

    1) Свойства контейнера:

    flex-direction:
    Определяет направление расположения flex-элементов
    (в строку, столбец и т.д.).

    justify-content:
    Управляет расположением элементов по главной оси.

    align-items:
    Выравнивает элементы по поперечной оси.

    align-content:
    Управляет расположением строк flex-элементов,
    если элементов несколько строк.

    flex-wrap:
    Определяет, будут ли элементы переноситься на новую строку.

    2) Свойства элементов:

    flex:
    Краткая запись свойств flex-grow, flex-shrink и flex-basis.

    flex-grow:
    Определяет, может ли элемент увеличиваться
    и занимать свободное пространство.

    flex-shrink:
    Определяет, может ли элемент уменьшаться
    при недостатке места.

    flex-basis:
    Задаёт базовый размер элемента до распределения пространства.

    align-self:
    Позволяет отдельно выровнять конкретный элемент.

    order:
    Изменяет порядок отображения flex-элементов.

3. Приведите примеры применения каждого свойства 
   и объясните, как они влияют на расположение и размер элементов.

Ответ:
    Примеры свойств контейнера:

    flex-direction:

    .container {
        display: flex;
        flex-direction: column;
    }

    Элементы будут располагаться вертикально сверху вниз.
    При flex-direction: column главная ось становится вертикальной, поэтому элементы располагаются сверху вниз.

    justify-content:

    .container {
        display: flex;
        justify-content: center;
    }

    Элементы будут выровнены по центру главной оси.
    Свойство влияет именно на расположение элементов,
    а не на их размер.

    align-items:

    .container {
        display: flex;
        align-items: center;
    }

    Элементы будут выровнены по центру поперечной оси.
    Если используется значение stretch,
    элементы могут автоматически растягиваться по высоте или ширине.

    align-content:

    .container {
        display: flex;
        flex-wrap: wrap;
        align-content: center;
    }

    Строки flex-элементов будут выровнены по центру контейнера.
    Может влиять на распределение свободного пространства между строками.

    flex-wrap:

    .container {
        display: flex;
        flex-wrap: wrap;
    }

    Элементы смогут переноситься на новую строку.
    Это помогает сохранять размеры элементов
    и предотвращает их сильное сжатие.

    Примеры свойств элементов:

    flex:

    .item {
        flex: 1;
    }

    Элемент будет занимать доступное свободное пространство.
    Размер flex-элементов станет гибким и будет автоматически распределяться.

    flex-grow:

    .item {
        flex-grow: 1;
    }

    Элемент сможет увеличиваться
    и занимать свободное место контейнера.

    flex-shrink:

    .item {
        flex-shrink: 0;
    }

    Элемент не будет уменьшаться при нехватке места,
    благодаря чему сохранит свой размер.

    flex-basis:

    .item {
        flex-basis: 200px;
    }

    Базовый размер элемента составит 200px
    до распределения свободного пространства.

    align-self:

    .item {
        align-self: flex-end;
    }

    Конкретный элемент будет отдельно выровнен
    относительно остальных элементов.
    На размер элемента свойство обычно не влияет.

    order:

    .item {
        order: 2;
    }

    Элемент изменит своё положение относительно других элементов,
    но его размер останется прежним.
